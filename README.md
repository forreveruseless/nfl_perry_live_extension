# 🏀 NFLPerry NBA Live Assistant — Firefox V5 Auto Draft

Эта версия умеет **сама выбирать игроков на NFLPerry**.

## Как работает Auto Draft

Расширение:

1. читает `Draft Pick X of 6` и текущую команду;
2. читает уже выбранных игроков со страницы;
3. считает рекомендации;
4. в зависимости от стратегии выбирает лучший вариант;
5. само нажимает `+ Select PG/SG/SF/PF/C/6TH`;
6. ждёт окно NFLPerry;
7. использует поле `Search PF...` / `Search C...` и т.д.;
8. ищет точное имя рекомендованного игрока;
9. кликает его;
10. проверяет, что игрок действительно появился в нужном слоте;
11. только после подтверждения ждёт следующий дроу.

Если любой шаг неоднозначен, **Auto Draft останавливается**, а не делает случайный клик.

## Стратегии

### POTENTIAL
Минимизирует потерю математического потолка.

Пример SAS:
- Tim Duncan → PF = потолок 296.0
- David Robinson → C = потолок 295.7

Поэтому POTENTIAL выбирает Duncan.

### EXPECTED
Выбирает вариант с максимальным ожидаемым итоговым рейтингом по будущим случайным командам.

### 295+
Выбирает вариант с максимальным шансом закончить с рейтингом ≥295.

## Безопасность

Auto Draft всегда запускается **OFF** после обновления страницы или перезапуска расширения.

Чтобы включить автоматические клики, нужно вручную нажать:

`AUTO OFF → AUTO ON`

Есть задержка 0.5 / 0.9 / 1.5 / 2.5 сек.

Если:
- команда не распознана;
- состав распознан не полностью;
- окно выбора не открылось;
- игрок не найден;
- NFLPerry не подтвердил выбор;

автоматический режим выключается.

## Установка

1. Распакуй ZIP.
2. Firefox → `about:debugging#/runtime/this-firefox`
3. Удали старую временную версию.
4. `Load Temporary Add-on`
5. Выбери `manifest.json` из папки `nflperry_live_extension_firefox_v5_autodraft`.
6. Обнови NFLPerry через `Ctrl+F5`.
7. Открой панель 🏀.
8. Выбери стратегию.
9. Нажми `AUTO OFF`, чтобы стало `AUTO ON`.

## Важно

Автоклик сделан по структуре окна, показанного на скриншоте:
- `Search PF...`
- `Drafting: Sacramento Kings`
- строки игроков вроде `Chris Webber (PF)`.

Если NFLPerry изменит это окно, Auto Draft безопасно остановится и покажет причину.
