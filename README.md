# 🏀 NFLPerry NBA Live Assistant — Firefox V6

## Главное исправление

В V5 выпадающие списки Firefox (`команда`, `стратегия`, `задержка`) могли открываться и сразу закрываться.

Причина была в PAGE SYNC: при чтении страницы расширение на мгновение ставило своей панели `display:none`.

V6 **никогда не скрывает панель во время синхронизации** и наблюдает только за `<body>` NFLPerry, а не за собственным интерфейсом расширения.

Поэтому dropdown/select теперь должны работать нормально.

## Автоматическая новая игра

Добавлен переключатель:

`После 6/6 автоматически начать новую игру`

После полного состава расширение:

1. сохраняет результат в статистику;
2. ищет однозначную кнопку с текстом вроде:
   - Play Again
   - Restart
   - New Game
   - Start New Game
   - New Draft
3. кликает её;
4. проверяет, что появился `Draft Pick 1 of 6` и пустой состав;
5. если Auto Draft был включён, продолжает следующую игру.

Если кнопку нельзя определить однозначно, расширение **не кликает наугад**.

Пришли скрин финальной кнопки NFLPerry — тогда можно сделать точное распознавание именно под неё.

## Вкладка «Статистика»

V6 автоматически сохраняет каждую игру, когда на странице распознаны все 6 игроков.

Сохраняются:

- итоговый `YOUR SCORE`;
- дата/время;
- PG;
- SG;
- SF;
- PF;
- C;
- 6TH;
- команда каждого игрока;
- его P/R/A.

Во вкладке **Статистика** показываются:

- количество сыгранных игр;
- лучший результат;
- средний результат;
- Top 10 результатов;
- полный состав каждого результата.

История хранится локально в Firefox.

## Установка

1. Распакуй ZIP.
2. Открой `about:debugging#/runtime/this-firefox`.
3. Удали V5.
4. Нажми `Load Temporary Add-on`.
5. Выбери `manifest.json` из папки `nflperry_live_extension_firefox_v6`.
6. Вернись на NFLPerry.
7. Нажми `Ctrl+F5`.
8. Открой 🏀.
