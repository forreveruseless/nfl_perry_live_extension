# 🏀 NFLPerry NBA Live Assistant — Firefox V7

## Новое: минимальный Potential

В блок Auto Draft добавлен **минимальный потенциальный максимум**.

Есть два режима.

### Свой порог

Например:

`295.0`

Если текущий точный Potential опустится ниже 295.0, расширение прекращает эту попытку и запускает новую.

### Мой HIGH SCORE

Можно поставить галочку:

`Использовать мой HIGH SCORE с NFLPerry`

Расширение читает строку самой страницы:

`HIGH SCORE: 291.4 P/R/A`

и автоматически использует `291.4` как текущий минимум.

Если позже HIGH SCORE станет выше, например `296.2`, порог автоматически станет `296.2`.

Если HIGH SCORE на странице временно не найден, используется лучший результат из локальной истории расширения.

---

## Умный ранний отказ

Расширение не обязательно ждёт, пока плохой игрок уже будет выбран.

Если текущая команда выпала, и **даже лучший доступный пик** оставит Potential ниже установленного минимума, V7 сразу отбрасывает попытку и перезапускает игру.

Пример:

```text
минимум: 295.0
текущий лучший вариант после дроу: Potential 294.6

→ игрок не выбирается
→ попытка сразу перезапускается
```

Это экономит время при длинном Auto Draft.

---

## Перезапуск

V7 сначала пытается найти нормальную кнопку `Restart / New Game / Play Again`.

Если в середине драфта NFLPerry не показывает такую кнопку, используется reload NBA Game Mode.

Есть защита от бесконечного reload-цикла: если один и тот же игровой state не изменился после reload, автоматизация останавливается.

---

## Статистика

Сохраняется прежняя вкладка:

- все завершённые игры;
- лучший результат;
- средний результат;
- Top 10;
- полный состав каждого результата.

---

## Установка

1. Распакуй ZIP.
2. Firefox → `about:debugging#/runtime/this-firefox`
3. Удали V6.
4. `Load Temporary Add-on`
5. Выбери `manifest.json` из папки `nflperry_live_extension_firefox_v7_threshold`.
6. На NFLPerry нажми `Ctrl+F5`.
7. Открой 🏀.

## Рекомендуемый режим для охоты за рекордом

- Auto Draft: ON
- Strategy: POTENTIAL или 295+
- Auto Restart после 6/6: ON
- Minimum Potential:
  - либо своё значение;
  - либо `Использовать мой HIGH SCORE`.

В таком режиме слабые попытки автоматически отбрасываются, а завершённые результаты попадают в статистику.
