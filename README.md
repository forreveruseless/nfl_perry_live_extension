# 🏀 NFLPerry NBA Live Assistant — Firefox V9

## Один человек нельзя выбрать дважды

Теперь разные сезоны и разные команды одного человека считаются **одним игроком**.

Например после выбора:

`Luka Dončić — DAL (2023)`

расширение уже не сможет выбрать:

`Luka Dončić — LAL (2026)`

и не будет использовать второго Luka в расчёте Potential / Expected / 295+.

Это правило применяется к любому игроку в базе.

## Ошибка Auto Draft = новая попытка

Если во время автоматической игры возникает игровая ошибка, расширение больше не остаётся в `AUTO STOP`.

Оно пытается:

`ошибка → restart/reload → Start Game → Draft Pick 1/6 → продолжить Auto Draft`

Например так обрабатываются:
- игрок не найден;
- окно выбора не открылось;
- NFLPerry не подтвердил клик;
- слот неожиданно занят;
- состав распознан не полностью;
- один человек оказался выбран дважды;
- нет допустимого выбора без повторов.

Защита от бесконечного reload-цикла сохранена.

## Установка

1. Распакуй ZIP.
2. Открой `about:debugging#/runtime/this-firefox`.
3. Удали V8.
4. `Load Temporary Add-on`.
5. Выбери `manifest.json` из папки `nflperry_live_extension_firefox_v9_unique_players`.
6. На NFLPerry нажми `Ctrl+F5`.
7. Открой 🏀.
